Задача: разарботать телеграм бота для проведения тайного санты

Механика: 
Пользователь должен иметь две основные функции: 
- организовать игру в тайного санту: создавший пользователь считается организатором
- вступить игру по пригласительному коду

Для каждой игры создается уникальный пригласительный код (8 символов)
Код получает организатор при создании (и может получить позже в информации об игре). 
Организатор игры может просматривать информацию о том какие пользователи подготовили подарки
Пользователь может указать что подготовил подарок

пользователь имеет возможность зарегистрироваться для участия в игре (один пользотель - один раз). При регистрации надо ввести пригласительный код и свои пожелания для подарка.

Организация игры проходит по следующей схеме:
1. Организатор создаёт игру и получает код и доступ к просмотру списка участников
2. Пользователи вступают в игру по пригласительному коду
3. Организатор может начать игру (теперь участники не могут добавляться)
4. Каждый участник получает пару - второго участника которому он готовит подарок (важно: один пользователь готовит один подарок, один пользователь получает один подарок, пользователь не может дарить подарок самому себе) 
5. пользователи отмечают если подарили подарки
6. Организатор может заархивировать игру (больше нельзя отмечать подготовку подарка)

Организатор имеет возможно просматривать список участников игры в формате:
```
Игра: <Имя которое задает организатор на старте>
Пригласительный код: `<Код для присоединения к игре>`
Участники:
- <юзернейм участника1 - кликабельно>: Подарок не готов
- <юзернейм участника2 - кликабельно>: Подарок готов
- <юзернейм участника3 - кликабельно>: Подарок не готов
```
